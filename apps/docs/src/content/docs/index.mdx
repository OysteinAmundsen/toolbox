## The Grid

A **single `<tbw-grid>` element** for sorting, filtering, grouping, editing and virtualization. No framework wrapper required.

<CardGrid>
  <Card title="Framework Agnostic" icon="puzzle">
    Pure TypeScript web component. Works natively in vanilla JS, React, Angular, Vue, Svelte, and any other framework.

    ```html
    <tbw-grid></tbw-grid>
    ```
  </Card>
  <Card title="High Performance" icon="rocket">
    Row virtualization, batched DOM updates, and a render scheduler keep scrolling smooth even with 100k+ rows.

    ```js
    grid.rows = rows; // 100k rows, still smooth
    ```
  </Card>
  <Card title="Plugin Architecture" icon="setting">
    {GRID_STATS.pluginCount} built-in plugins for selection, editing, filtering, grouping, column reordering, export, and more. Tree-shakeable — only pay for what you use.

    ```js
    import '@toolbox-web/grid/features/selection';
    ```
  </Card>
  <Card title="Tiny Footprint" icon="seti:zip">
    Core bundle ~{GRID_STATS.coreGzipKb} kB gzipped. Each plugin is a separate entry point, so unused ones never reach your bundle.

    ```js
    import '@toolbox-web/grid';
    ```
  </Card>
</CardGrid>

## Framework Adapters

Optional. They add template-driven renderers, typed props, and patterns idiomatic to each framework. The grid works without them.

<CardGrid>
  <Card title="Angular" icon="seti:angular">
    Directives for template-driven column renderers and editors, reactive forms integration, and `ControlValueAccessor` support.

    [Angular docs →](/grid/angular/getting-started/)
  </Card>
  <Card title="React" icon="seti:react">
    `<DataGrid>` component with JSX renderers, `useGrid` / `useGridEvent` hooks, and React Query integration patterns.

    [React docs →](/grid/react/getting-started/)
  </Card>
  <Card title="Vue" icon="seti:vue">
    `<DataGrid>` component with slot-based renderers, `useGrid` / `useGridEvent` composables, and `markRaw` patterns.

    [Vue docs →](/grid/vue/getting-started/)
  </Card>
</CardGrid>
